关于 · 合规说明
这一页里的每一句话，都是模型在你点开它的那一刻现写的。下面是它的来源、它会怎么出错，以及你的数据去了哪里。

⚑你现在打开的是在线版

这一版没有服务端：页面直接在浏览器里调用模型接口（默认 DeepSeek），你填的 API Key 只写进你这个浏览器的 localStorage，不会上传到任何地方——除了它本来就要发给模型服务商的那次请求。

你长出来的星图、看过的讲义，同样只存在这个浏览器里。换台电脑、换个浏览器、或者清一次浏览器数据，就会回到初始状态。想让成果落成一个可以备份的文件，请用仓库里的服务端模式（start-server.bat），数据会写进本机的 star.db；也可以点顶栏的「导出」，把整张星图下载成 .md 文件夹。

在线版的定位是「先试试看」；它和完整版共用同一份前端代码，功能一致。

唯一换不了的是一样东西：模具。讲义「长什么样」定义在服务端的 templates/*.rules 里，这个版本读不到那些文件，只能用内置的那一副默认模具。

✦内容由 AI 生成

每一份讲义、每一个概念名、每一条「常见误解」，都由大语言模型（默认 deepseek-chat，经 DeepSeek API）实时生成。星图的形状也一样：哪些概念该被拎出来、它们之间是什么关系，由模型决定，前端只负责排布。

这个项目没有预置知识库。离线模式（双击 HTML、断网演示）里内置了少量样例内容，页面上会标注；除此之外没有人工撰写的讲解文字。

⚠它一定会说错

模型会编。它可能给出错误的年份、人名、公式，也可能把两个概念的关系说反。

生成之后有一道零 API 成本的字符串自检（17 项，例如「事实必须一句话说完」「洞察不能只是空话」「不要重复这个星团里已有的概念」）。不合格时会在讲义末尾打一行 ##CHECK fail …，并在本机的生成记录里记为一次不合格 —— 但它不会自动改写，重写与否由你按讲义右上角的 ↻ 决定。自检只能拦住格式和空洞，拦不住错误的知识。

所以请把它当成一个把「不懂」变成「可以追问的结构」的工具，而不是答案来源。要写进作业、论文、汇报，或拿来做决定的数字和结论，请回到教材、论文或官方来源核对。

⇢你的数据去了哪里

  • 你问的每个问题都会以一次 HTTP 请求发给上面配置的模型服务商（默认 DeepSeek）。发送的内容包括：你的问题原文、当前节点的名字、以及同一个星团里已经出现过的概念名（只用于避免重复给出同一个概念）。
  • 所以请不要在这里输入个人隐私、未公开的研究数据或受保密约束的材料。
  • 星图结构、讲义正文和生成记录只写入本机的 star.db（SQLite 单文件），不上传、不统计、不向任何第三方共享。删掉这个文件就等于清空全部数据。
  • 页面不设 cookie，不接第三方统计、广告或追踪脚本。唯一的外部资源是用来排版数学公式的 KaTeX（可选，从 CDN 加载；加载失败时公式退化成纯文本，不影响阅读）。

⚿凭据与部署边界

服务端模式下，API Key 由本机 Node 服务读取 config.json，浏览器只在设置面板里把它发往 127.0.0.1 一次。但 config.json 里是明文——请不要把它提交到公开仓库或分享出去。

直连模式（双击 HTML）下没有服务端，Key 会以明文存进这个浏览器的 localStorage。不要在公用电脑上用直连模式。

服务只监听 127.0.0.1，且所有 /api/* 接口没有任何鉴权。这意味着它只能在本机使用。一旦挂到公网，/api/lecture 就等于一个任何人都能调用的开放模型代理，会花光你的额度。要公开部署，必须先加访问令牌、限流和 HTTPS。

⌘依赖与授权

零第三方运行时依赖：没有 package.json，没有 npm 包，没有前端框架。服务端只用 Node 内置的 http / fs / path 与内置 SQLite（node:sqlite），其余代码均为本项目自己写的。
