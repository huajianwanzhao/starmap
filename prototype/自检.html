② 正在检测 JavaScript…
如果这几秒后还是这句话，说明这个浏览器没有执行 JavaScript。

（要 JS 才能读到）

（要 JS 才能读到）

（要 JS 才能读到）

（要 JS 才能读到）
本地存储
（要 JS 才能读到）
能否连模型接口
（要 JS 才能读到）
上面的判定如果是「没有执行 JavaScript」，那么星图在这个设备上不会响应任何点击 —— 不是星图坏了， 是这个浏览器（或文件管理器 / 微信的内置预览）把脚本关掉了。
手机上的「快速查看 / 预览」几乎都会关掉脚本；想在手机上用，得从电脑起一个局域网服务， 用 http://电脑IP:5173 打开。
